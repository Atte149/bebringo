# Озвучка и гибридный аудиодвижок Bebringo

В Bebringo реализован **двухуровневый гибридный аудиодвижок**, гарантирующий 100% работу офлайн, студийное нативное произношение и нулевую задержку воспроизведения.

---

## 1. Архитектура и приоритеты

1. **Уровень 1 (Студийные предгенерированные ассеты в APK):**
   - Все 160 уникальных реплик курса (аудирование, словарь, инсайты, диктанты, диалоги) предгенерируются заранее и сжимаются в формат **Ogg Opus (24 kbps, 24 kHz)**.
   - Файлы хранятся в `app/src/main/assets/audio/ro_a1/*.ogg`.
   - Общий объём всех 160 фраз курса A1 составляет всего **~777 КБ** (меньше 1 МБ!).
   - Воспроизведение происходит через нативный Android `MediaPlayer` напрямую из ассетов (`context.assets.openFd(...)`).
   - Задержка старта — **0 мс**, интернет не требуется, системные голосовые пакеты Android не требуются.

2. **Уровень 2 (Фоллбек на системный TextToSpeech):**
   - Используется для динамических слов (например, когда пользователь тапает на произвольное незнакомое слово в тексте для свободного чтения, которого не было в словаре курса).
   - Локаль синтезатора берётся из шапки трека (`ttsLocale: "ro-RO"`).

3. **Уровень 3 (UX Fail-Safe — защита от блокировки уроков):**
   - На шагах аудирования (`ListeningStep`) и диктантов (`DictationStep`) аудио запускается автоматически только если в настройках включён «Автозапуск аудио». По умолчанию он выключен: пользователь нажимает «Прослушать».
   - Кнопка воспроизведения показывает статус проигрывания (`isPlaying`).
   - Присутствует кнопка-страховка: **«Не слышно звук? Показать фразу»** / **«Показать подсказку»**. Если пользователь находится в шумном месте, отключил громкость или у него не работают наушники, урок **никогда не зависает**. Если звук приложения выключен, фраза показывается сразу.
   - `MediaPlayer` и TTS используют `USAGE_MEDIA`, поэтому системная медиа-громкость и беззвучный режим реально влияют на озвучку. Кнопка mute в верхней панели урока выключает звук на весь урок.

## 2. Пайплайн генерации аудио для авторов треков

Для озвучки любого YAML-трека (румынский язык, медитация, писательские практики) используется скрипт:

```bash
# Генерация аудио для курса румынского A1
python3 tools/generate_audio.py --track-yaml app/src/main/assets/course/a1.yml

# Принудительная перегенерация существующих файлов
python3 tools/generate_audio.py --track-yaml app/src/main/assets/course/a1.yml --force
```

Скрипт:
1. Парсит YAML-файл трека и собирает все уникальные тексты.
2. Синтезирует студийную речь через нативные нейроголоса (`ro-RO-EmilNeural` для мужских реплик/бобрика, `ro-RO-AlinaNeural` для женских реплик в диалогах).
3. Перекодирует аудио через `ffmpeg` в ультра-компактный `libopus` (24 kbps, 24000 Hz, моно).
4. Создаёт хэш-карту `manifest.json`, связывающую нормализованные фразы с файлами `.ogg`.
